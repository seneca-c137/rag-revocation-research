# Research Project Brief

## Objective
Revocation-Aware Dynamic Access Control for RAG Systems.

## Stack
Java 21, Maven, JUnit 5, Jackson.

## Existing Architecture
- UserManager
- PermissionManager
- AuthorizationService
- MetadataFilter
- RetrievalService
- CacheService
- ExperimentRunner
- ExperimentLogger

## Requirements
- Dynamic permission validation
- Metadata-based filtering
- Permission revocation
- Cached retrieval revalidation
- Experimental test execution
- CSV/JSON result generation

## Constraints
- Preserve existing implementation.
- No frontend.
- No unnecessary dependencies.
- No cloud infrastructure.
- No fabricated results.
- Modify only necessary files.
- Prioritize correctness and reproducibility.
